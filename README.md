# Survival Analysis Actuarial Project

An actuarial survival analysis project using R, Kaplan-Meier estimation, and Cox proportional hazards modelling.

## Project Overview

This project applies survival analysis techniques in R to analyse time-to-event data.

The objective is to estimate survival probabilities, identify potential risk factors, and demonstrate how actuarial and statistical methods can support risk assessment and decision-making.

## Tools and Skills

- R
- Survival Analysis
- Kaplan-Meier Estimation
- Cox Proportional Hazards Model
- Data Visualisation
- GitHub

## Key Findings

- Survival probability declined steadily over time.
- The Kaplan-Meier curve shows how survival likelihood changes across the observation period.
- The Cox proportional hazards model was used to examine the relationship between age, sex, and hazard rates.
- This type of analysis can support actuarial risk assessment and insurance-related decision-making.

## Business Relevance

Survival analysis is widely used in actuarial science, insurance, healthcare analytics, and risk management to model time-to-event outcomes and estimate future risk exposure.
